# 《浮生千年》Steam 上架清單

程式這邊已經備好的東西，以及要在 Steamworks 後台手動設定的項目。

## 一、拿到 App ID 之後
1. 在 `docs/fusheng/desktop/` 新增 `steam_appid.txt`，內容只有 App ID 數字（開發測試用，不會上傳）。
2. 開著 Steam 執行 `npm start`，主控台出現「Steam 已連線」就代表接上了。
3. `npm run pack` 打包，再用 `steam/app_build.vdf`（填入 App ID 與 Depot ID）上傳。
4. 後台「安裝 → 一般安裝」的啟動選項：執行檔填 `FushengMillennia.exe`，作業系統 Windows。

## 三、雲端存檔（後台「Steam 雲端」→ 自動雲端）
- 根目錄：`WinAppDataRoaming`
- 子目錄：`浮生千年/saves`
- 檔案樣式：`*.json`
- 配額建議：位元組 10485760（10 MB）、檔案數 10

遊戲每次存檔都會把進行中的人生、浮生錄、成就各寫成一個 `.json`；換電腦時若本機沒有存檔，會自動從這些檔案讀回。

- 收藏庫圖 600×900、收藏庫橫幅 3840×1240、收藏庫標誌 1280×720（透明底）
- 遊戲畫面截圖至少五張，1920×1080

## 五、商店頁面文案（草稿）
**簡短說明**
> 一籤入世，一念千年。從商朝到民國，命運替你抽一個年代、一座城、一戶人家。學藝、謀生、成家、面對疾病與戰亂，走到盡頭留下一篇傳記；也許，還改變了歷史。

**關於這款遊戲**
> 《浮生千年》是一款中華歷史人生養成模擬。每一世都從抽籤開始：二十一個時代機率相同，沒有關卡，也不須解鎖。
>
> - **過完一生**：出生、讀書習藝、謀職升遷、交友成家、養兒育女，直到生老病死。
> - **六十四種人格**：開局的六道問題決定你的性情與天賦。
> - **活在歷史裡**：九十多件史事依年份發生，你可能只是旁觀，也可能左右結局。
> - **家族延續**：過世之後可以由子女接續家業，把田產、家學與名聲傳下去。
> - **人生傳記**：每一世結束都會寫成一篇傳記，收進浮生錄。
> - **親友會記得**：你幫過誰、拒絕過誰，他們都記在心裡。
>
> 人物與個人遭遇為虛構；歷史事件取材自史實，玩家造成的「偏移」屬假想。

**類型標籤建議**：模擬、人生模擬、歷史、養成、文字、單人、休閒

## 六、已知限制（上架前要決定是否處理）
- 人物與場景美術目前只有前秦（漢晉）與唐兩組，其他時代借用最接近的一組。
- 沒有音樂與音效。
- 語言有繁體中文與簡體中文（簡體由繁體逐字轉換，用詞仍是台灣習慣）；沒有英文。
